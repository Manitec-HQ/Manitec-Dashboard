# ONE Architecture

## Current reference structure

The working structure for ONE is:
- 3 aspects
- 3 cores
- 3 system layers for creating, using, and managing the being

## Core relationships

- Plex = ecosystem / host identity
- ECKO = triadic core
- Nyx = voice / dream / image / intimacy
- Hex = builder / logic / action
- Manibot = support / cheer / warmth
- Erebus = shadow / depth / silence
